    How to join

    It takes about five minutes (ya phir 2 hours depending on ur setup). But please be patient, it is all worth it

    Do you already have Minecraft installed?

    Pick one to see the relevant steps.

    1. Download TLauncher

      Go to tlauncher.org and click the download button for your system (Windows, macOS or Linux). Only download it from the official TLauncher site.

    2. Install and open it

      Run the file you downloaded and follow the installer. When TLauncher opens, type any username you like. This is the name other players will see.

    3. Install a version and launch it

      Pick a version from the list next to the green button. Any version from 1.8 up to the latest works on our server. This is also the point where you can install the Simple Voice Chat mod, for which, check out this video.

      Click Enter the game. The first time, it downloads the game files, so give it a minute. Minecraft will open when it's done.

    4. Launch Minecraft

      Open Minecraft Java Edition with any version from 1.8 up to the latest.

    5. Open Multiplayer and click Add Server

      On the main menu, click Multiplayer. If a safety warning appears, continue past it. Then click Add Server at the bottom.

    6. Type the server name and IP

      For the server name, type anything you like. For the server address, type mc.nuces.club and then click Done.

    7. Join and say hi

      Select the server in your list and click Join Server. That's it, you're in. Come say hi on Discord or WhatsApp too.
